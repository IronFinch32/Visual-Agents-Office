# UX — session-sync
- Geen nieuwe schermen of flows. Elke sessiekamer en zijn regel op het CEO-bord tonen de stand van díe sessie.
- Nieuwe sessie: vergaderzaal (fase 0), lege tijdlijn, geen SHIPPED-feest, geen kanban, geen overdracht-animatie.
- Afgeronde sessie: blijft "klaar"/"Opgeleverd · iedereen is naar huis", ook als een nieuwe sessie in hetzelfde project begint.
- Rol-label zonder `~` alleen bij een exact signaal; geen rol op een sessie die niets doet.
