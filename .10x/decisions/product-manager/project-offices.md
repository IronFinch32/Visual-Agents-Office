# PM — project-offices
## Stories
1. I see one office per project, so parallel projects are separated.
2. Inside, I see every running subagent working at its own desk with what it does.
3. After a run I still see the team's result (✓) until I give a new prompt.
4. I can zoom into one office and get warned if someone elsewhere waits.
## Success
- A session that spawns N parallel subagents shows N seated workers within 1 s.
- Waiting agents are noticeable in building view without zooming.
