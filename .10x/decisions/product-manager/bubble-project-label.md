# PM — bubble-project-label
**User story:** Als CEO wil ik in de tekstballon van een agent zien voor welk project hij werkt, zodat ik in één oogopslag zie wie waar bezig is.
**Acceptatie**
1. Elke tekstballon (werkt / wacht / klaar) in de bedrijfsweergave, afdelingen én Flexwerkplek, toont bovenaan de projectnaam met het projectkleurblokje.
2. De statusrand (blauw/rood/groen) en de activiteitstekst blijven zoals ze waren.
3. Geen projectnaam → gewone ballon zonder kopregel.
4. CEO-verdieping en `?weergave=kamers` ongewijzigd.
**Buiten scope:** denk-wolkje, lounge-babbels, subagents.
