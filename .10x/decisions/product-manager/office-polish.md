# PM — office-polish
## Stories
1. From across the room I can see *what kind* of work each agent does (monitor content, outfit).
2. A waiting agent is unmissable (spotlight + dimmed rest).
3. The office feels alive and layered, not a flat diagram.
4. The task of each session is readable on its whiteboard.
## Success
User judges it 'mooier met gelaagdheid'; waiting still noticed < 2 s; no regression in tests.
