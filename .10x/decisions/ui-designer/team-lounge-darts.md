# UI — team-lounge-darts
- Dartbord: pixelsprite ~12×12 op houten standaard, rood/groen/zwart/crème ringen, bull rood; werplijn als dunne lichte streep op de vloer. Pijltjes: 2px lijn met gekleurde veer in accentkleur van de werper.
- Pose 'throw': arm omhoog naar voren tijdens worp. Ballonnen via bestaande `say`.
- Hergebruik sprite-stijl uit `tenx-sprites.js`; geen nieuwe tokens.
