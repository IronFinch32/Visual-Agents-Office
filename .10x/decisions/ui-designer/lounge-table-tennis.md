# UI — lounge-table-tennis
Stijl volgt pooltafel/dartbord (pixel-rects, schaduwellips, pootjes).
- Tafel: blad groen #2e7d4f met witte rand 1px #e8e8e8, middenlijn langs, net in het midden: donkergrijze paal + lichtgrijs net 2px hoog. Pootjes #3a3a44, schaduw rgba(0,0,0,.25).
- Solo: rechter helft opgeklapt = staande plaat 18×10 boven het net, zelfde groen iets donkerder (#25663f).
- Batje: 3×3 rood #d64545 met 1px handvat #8a5a2b; bij slag 2px naar voren.
- Balletje: 1×1 wit #fff (2×2 als het hoog is), schaduw 1×1 rgba(0,0,0,.35) op het blad.
